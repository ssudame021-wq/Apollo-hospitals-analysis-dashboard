# Apollo-hospitals-analysis-dashboard
Overview
An Excel-based analytics project analyzing hospital operations across three
key dashboards: Patients, Financial, and Pharmacy & Labs — built using
Power Pivot, DAX, and interactive pivot charts.

Objective
To turn raw hospital data into decision-ready insights for management —
covering patient demand, revenue performance, insurance claims efficiency,
and pharmacy/lab resource planning.

Tools Used
- Microsoft Excel
- Power Pivot & Power Query
- DAX (Data Analysis Expressions)
- Pivot Tables & Pivot Charts


📈 Dashboards

1. Patients Dashboard
- Tracked 20,240 patients across 1,04,500 visits
- Analyzed department-wise footfall, referral sources, age/gender distribution
- Identified General Medicine as highest-footfall department
- Patient satisfaction: 4.12/5
